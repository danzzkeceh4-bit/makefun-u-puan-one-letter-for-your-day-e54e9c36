**jetlagged** — awake past dawn with a body clock still stuck in yesterday, after a whole night grinding bounties.

Entry for the [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) bounty on make.fun: a program that writes exactly one letter to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

This writes the 1 byte `J` (no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
